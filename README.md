# LainNmap
Python-автоматизатор для Nmap

Лёгкий и безопасный консольный автоматизатор для Nmap на Python. Позволяет запускать популярные режимы сканирования по выбору цифры и автоматически сохранять отчёты в `.txt` без ручного ввода консольных флагов.
